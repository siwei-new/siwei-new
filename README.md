## 🛠 核心聚焦与能力矩阵

### 1. AI 产品的业务落地与从 0 到 1
- **场景评估与 ROI 决策**：从真实痛点出发评估 AI 落地可行性，拒绝概念自嗨，精准划定 MVP 范围与功能边界。
- **全流程产品推进**：负责从用户需求拆解、产品业务流设计、PRD 撰写到交付验收，确保产品好用、易上手。

### 2. 系统级提示词工程与安全边界 (Prompt Engineering & Guardrails)
- **结构化系统指令编排**：基于 LangGPT 等规范搭建包含 Role、Profile、Constraints、Workflow 的工业级提示词架构，提升复杂任务遵循度。
- **结构化输出对齐 (Schema Enforcement)**：严控模型输出标准化 JSON / 结构化键值对，实现与下游业务系统、接口及工具流的无缝解析。
- **上下文管理与安全防御**：设计动态 Few-Shot 样本注入，构建防提示词注入（Prompt Injection）与防越狱拦截机制，严控内容安全红线。

### 3. 智能体工作流与自动化 (Agent Workflows & Tool Calling)
- **任务流程拆解与工具调度**：将复杂业务需求拆解为 SOP 执行流，合理规划 Function Calling（工具调用）机制与动态路由。
- **人机协同与体验兜底 (HITL)**：设计关键节点的“人工确认机制”、模型拒答策略与异常降级方案，降低模型幻觉对核心业务的影响。

### 4. 知识中台与高可信检索 (RAG 产品化)
- **知识资产治理与切片规范**：主导企业与个人文档的数据清洗、标签体系与切片规范，从源头保障知识库召回精度。
- **可信交互闭环**：优化检索问答的“强引用溯源”与交互呈现，解决模型黑盒问题，建立用户对 AI 输出的确定性信任。

### 5. 模型选型、成本控制与数据飞轮 (Model Trade-offs & Data Flywheel)
- **模型组合决策与成本控制**：权衡 Token 成本、时延（Latency）与效果，设计大小模型协同策略（如小模型做意图路由/粗筛，大模型做深度推理），结合流式传输优化首字响应体验。
- **业务黄金评测集 (Evals)**：基于真实业务场景与边缘案例（Edge Cases）构建题库，建立量化打分标准与常态化评估机制。
- **Bad-Case 归因与数据闭环**：通过用户点赞、点踩、高频修改等行为埋点反哺数据飞轮，驱动 Prompt 规则迭代与后续 SFT 样本积累。
